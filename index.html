Unit 7 Security Architecture

Five Major Security Components & Production Recommendations

Layer Component Purpose & Risk Reduction Prototype Status
01 User Devices & Endpoints University laptops, desktops, and tablets used by students, staff, and administration. Active UI
02 Identity & Authentication University Single Sign-On (SSO), Multi-Factor Authentication (MFA) for privileged staff/admin accounts, and role claims. Simulated Role
03 Security Gateway & Web Server TLS/HTTPS transport encryption, Web Application Firewall (WAF), rate limiting, and secure session filtering. Design Spec
04 Application / API Server Server-side role authorization, strict input validation (kWh, kL, kg), and CSV/PDF report generation. Validation Rules Live
05 Private Database & Backups Encrypted private network database with automated backups, restoration drills, audit logs, and soft-archive retention. Audit + Soft Delete Live
